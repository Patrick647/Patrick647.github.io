# Dongxu Wang Academic Website

Personal academic website for Dongxu Wang, focused on clinical pharmacy practice, health services research, health communication, publications, projects, and professional experience.

## Stack

- Hugo
- Hugo Blox Academic CV
- Tailwind CSS
- Pagefind
- GitHub Pages / Netlify

## Local Development

```bash
pnpm install
pnpm run dev
```

## Production Build

```bash
pnpm run build
```

The generated site is written to `public/`.

## Content

- Profile and CV: `data/authors/me.yaml`
- Publications: `content/publications/`
- Projects: `content/projects/`
- Presentations: `content/presentations/`
